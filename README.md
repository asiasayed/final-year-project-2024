# New Mothers Support Website – Wix Prototype

Final project in **Information Systems Analysis & Design** – Sapir Academic College.  
Design and UX prototype of a website for new mothers in the Bedouin community, providing accessible guidance from pregnancy through early motherhood.

## Overview
The project analyzes user needs and designs a structured information website to replace scattered, hard-to-access resources. The prototype was implemented using **Wix**.

## What’s Included
- User research & survey analysis  
- Requirements definition (FR / NFR)  
- Process & system models (DFD, Process Flow, Use Case)  
- Feasibility study and platform comparison  
- UX structure and screen design  
- Interactive Wix prototype

## Main Features
- User registration & login
- Topic-based navigation (pregnancy, birth, after birth)
- Search function
- Knowledge categories and guided content
- Community / forum concept
- Expert consultation concept
- Hebrew & Arabic interface design

## Goal
Deliver a simple, culturally adapted, and user-friendly digital resource for new mothers.
